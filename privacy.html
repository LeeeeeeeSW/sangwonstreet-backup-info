도구와 운영자

상원스트리트 백업(SangwonStreet Backup)은 운영자 본인 1명이 사용하는 로컬 데스크톱 도구입니다. 운영·문의 주소는 sangwon5363@gmail.com입니다.

Google 데이터 접근과 이용

본인 동의를 통해 Google Drive의 drive.file 권한을 요청합니다. 이 앱이 생성하거나 사용자가 앱에 명시적으로 허용한 백업 파일·폴더와 그 파일의 이름, 식별자, 크기, 해시, 수정 시각, 공유 상태 등 필요한 메타데이터를 백업·복원·무결성 확인에 사용합니다. 계정의 모든 Drive 파일을 검색하거나 읽는 전체 Drive 권한은 요청하지 않습니다.

보관과 보호

백업 자료는 본인 노트북과 본인 Google Drive의 비공유 보관 위치에 저장합니다. OAuth 구성과 토큰은 노트북의 접근 제한된 로컬 경로에 저장하며 일반 로그, 소스 저장소, 공개 사이트, Drive 백업 묶음에 포함하지 않습니다. Google과의 API 통신에는 HTTPS를 사용합니다. 이것은 백업 파일의 종단간 암호화를 의미하지 않습니다.

공유와 외부 AI

Google은 사용자가 선택한 저장·인증 제공자입니다. 앱이 Google 사용자 데이터를 광고, 판매, 외부 AI 학습·질의에 사용하거나 다른 사용자에게 공개 공유하지 않습니다. Google 데이터의 이용은 공개한 백업·복원 기능과 Google API Services User Data Policy의 Limited Use 요구에 한정합니다.

보유·삭제와 동의 철회

기존 실패·복원 증거는 자동으로 삭제하지 않습니다. 사용자는 Google 계정의 연결된 앱 관리에서 접근 동의를 철회할 수 있고, 본인 Drive 파일과 로컬 백업을 직접 관리할 수 있습니다. 동의 철회는 이미 저장한 백업 파일을 자동 삭제하지 않습니다. 삭제 전에는 필요한 복원점을 따로 보관해야 합니다.

이 공개 안내 사이트

안내 페이지에는 OAuth 토큰, 계좌, 원장, 운영 로그, Google 백업 파일을 게시하지 않습니다. 앱이 별도 분석 스크립트나 광고 추적을 추가하지 않습니다. 웹 호스팅 제공자는 자체 정책에 따라 접속 로그 등 통상적인 서버 데이터를 처리할 수 있습니다.
